# 🍅 番茄钟

一个零依赖、单文件的番茄工作法计时器网页应用。纯 HTML/CSS/JavaScript 实现,无需联网、无需安装,双击即用。

## ✨ 功能特性

- **自主设定时间** — 专注、短休息、长休息时长均可自定义;另有独立「自定义」模式,可设定任意 1~600 分钟倒计时
- **经典番茄循环** — 每完成 N 个番茄(默认 4 个)自动进入长休息,环内圆点直观显示本轮进度
- **统计面板** — 今日完成番茄、今日专注时长、今日休息次数、累计番茄,以及近 7 天完成趋势图
- **直观的时间流逝** — 渐变发光进度环随剩余时间平滑消退;剩余 ≤10% 时数字脉动提醒;浏览器标签页标题实时显示倒计时
- **多模式配色** — 专注=番茄红、短休息=绿、长休息=蓝、自定义=紫,整页色调随模式切换
- **完成提醒** — 提示音(Web Audio 合成,上升/下降音阶)、桌面通知、页内消息
- **可选自动衔接** — 可开启自动开始下一轮
- **本地持久化** — 所有设置与统计数据保存在浏览器 localStorage,跨天自动切换

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可(双击文件或拖入浏览器)。

### 快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 开始 / 暂停 |
| `R` | 重置当前计时 |
| `S` | 跳过当前阶段 |
| `1` ~ `4` | 切换 专注 / 短休息 / 长休息 / 自定义 |

## 🎨 自定义配色

页面所有颜色定义在 `index.html` 顶部 `<style>` 的 `:root` 与四个 `body[data-mode]` 变量块中,修改 CSS 变量即可更换主题色:

- `--accent` / `--accent-soft` — 主色调及其淡色
- `--g1` / `--g2` — 进度环与主按钮的渐变色
- `--track` — 进度环轨道色(主色调的深阶)
- `--page` / `--surface` / `--surface-2` — 页面与卡片表面色

## 🛠 技术说明

- 计时采用**时间戳差值**计算(而非累加),后台标签页/系统睡眠后回到页面仍保持准确
- 数据存储于 `localStorage`(键 `pomodoro-app-v1`),90 天前的日数据自动清理
- 提示音由 Web Audio API 实时合成,无任何音频资源文件
- 无第三方库、无外部请求,完全离线可用
